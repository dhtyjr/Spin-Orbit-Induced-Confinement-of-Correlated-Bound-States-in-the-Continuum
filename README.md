# Code and Data

This repository contains the code and experimental data associated with the manuscript

**"[Manuscript Title]"**

The repository is organized as follows:

- `code/`: Python scripts used for data processing and figure generation.
- `data/`: Experimental data used by the corresponding plotting scripts.

The scripts and data folders are organized according to the figure numbers in the manuscript. For example, the data required by `code/fig3.py` are stored in `data/fig3/`.
